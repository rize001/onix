ONIX MESSENGER v162 — RUST + SLINT

1. Сначала запустите свою версию server.bat.
2. Дождитесь строки ONIX MESSENGER: http://localhost:PORT/.
3. Положите OnixMessenger.exe рядом с onix-config.cmd или оставьте стандартный порт 8080.
4. Запустите OnixMessenger.exe.

Клиент не содержит и не запускает сервер.
Порт определяется из ONIX_SERVER_URL, ONIX_PORT или onix-config.cmd; по умолчанию используется http://localhost:8080.
Технологии: Rust + Slint + Winit software renderer.
Не используются WebView, WebView2, Edge, Chromium, Electron или Wails.
