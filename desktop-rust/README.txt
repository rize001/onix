ONIX MESSENGER v161 — RUST + SLINT

1. Сначала запустите свою версию server.bat и дождитесь localhost:8080.
2. Запустите OnixMessenger.exe.

Клиент не содержит и не запускает сервер. Он подключается только к http://localhost:8080.
Технологии: Rust + Slint + Winit software renderer.
Не используются WebView, WebView2, Edge, Chromium, Electron или Wails.
